# TECH-NEWS-RESEARCH-AGENT
Autonomous Tech News Research &amp; Distribution Agent built with n8n. Aggregates news from Hacker News, TechCrunch, and The Verge, enriches articles using Tavily AI search, identifies the most important technology stories with LLMs, and automatically delivers curated news digests to Gmail and Discord.
